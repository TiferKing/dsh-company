## 2026-09-06：中断与重载后的员工活动恢复

- 原因：插件缺席期间的 Host 状态事件无法更新存档。没有未完成工作或 HR 评估的 `working` 员工会被调度器跳过；快照和概览又将旧 `working` 当作仍在运行的证据。
- 恢复：调度入口对照当前会话校准遗留状态，先回收过期投递准备，再释放已停止轮次的预留。工作与 HR 评估的恢复保留原 capability；无未完成任务的员工回到可调度状态。员工会话创建和卸载补充触发恢复，调度始终查找当前注册的 Founder。
- 竞态保护：事务内重新核对公司、员工 session ID 与 Agent 实例；延迟活动事件读取当前 Host 状态，避免旧 idle 事件覆盖新 running 或释放新预留。插件卸载后尚未完成的事件处理不能继续改写员工活动。
- 显示：活跃人数与运行标签只依据真实会话活动；暂停、失败和退休标签继续保留，未完成任务仍计入部门负载。
- 本轮修改不改变磁盘 schema，不修改实际公司数据，不安装到用户的 Web profile。
- 验证：新增 16 项重载、异步竞态、快照及界面回归，既有部门负载检查改为模拟真实运行会话。`pnpm verify` 通过：Host/Client 类型检查、246/246 项测试、生产构建和 `dsh-company@0.16.1` 包加载检查；`git diff --check` 通过。
